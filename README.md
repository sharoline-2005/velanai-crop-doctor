# 🌱 Velanai Crop Doctor

AI-Powered Plant Leaf Disease Detection Web Application

---

## 📌 Project Description

Velanai Crop Doctor is a modern AI-based web application designed to help farmers and agricultural researchers detect plant leaf diseases using image-based prediction.

Users can upload a plant leaf image and receive instant disease predictions powered by deep learning models from Hugging Face.

---

## 🚀 Tech Stack

### 🖥 Frontend
- React (with TypeScript)
- Vite
- Tailwind CSS
- i18n (Multi-language Support)
- ESLint
- Vitest

### 🤖 AI / ML Backend
- Python
- PyTorch
- Hugging Face Transformers
- Vision Transformer (ViT) Models
